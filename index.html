☁ Google Drive Sync

Einmalig einrichten (~5 Min):
  1. console.cloud.google.com → Neues Projekt
  2. APIs → Google Drive API aktivieren
  3. OAuth-Zustimmungsbildschirm → Extern
  4. Anmeldedaten → OAuth-Client-ID → Webanwendung
  5. Autorisierte JS-Quellen: deine URL eintragen
  6. Client-ID unten einfügen & speichern

Verbunden:

Als App installieren

Netlify Drop (einfachste Option):
  1. app.netlify.com/drop öffnen
  2. RiRoCal.html reinziehen → sofort eine URL
  3. In Chrome auf Android: Menü → "Zum Startbildschirm"

GitHub Pages:
  1. github.com → Neues Repo → Datei hochladen als index.html
  2. Settings → Pages → Branch: main → Save
  3. URL: deinname.github.io/reponame
